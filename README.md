# Faith Connect Community (Static Next.js Site)

Static, fast, and future-ready website for Faith Connect Community NPC.

- Next.js 15 + App Router
- TypeScript
- Tailwind CSS
- Static Export (no backend)
- Content via TypeScript files in /data

## Commands

- dev: npm run dev
- build static: npm run build (exports to `out/`)
- start: npm start

## Structure

- app/ — pages
- components/ — UI building blocks
- data/ — content (sermons, events, etc.)
- public/ — static assets

## Deploy

- Vercel (recommended) or any static host (Netlify, Cloudflare Pages, etc.)
